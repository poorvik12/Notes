## ✨ Features

* 📝 Create notes with a title and description
* 💾 Notes persist using **LocalStorage**
* 🗑️ Delete notes instantly
* 🚫 Prevents empty notes from being created
* 🔍 Handles long titles and descriptions
* 📱 Responsive layout for different screen sizes
* 🎨 Clean dark-themed interface
* ⚡ Fast and lightweight React application

## 📸 How It Works

### 1. Add a Note

Enter a title and description and click **Add Notes**.

### 2. Notes Are Saved

Notes are automatically stored in the browser using LocalStorage.

### 3. Refresh Without Losing Notes

Refreshing the browser doesn't remove your notes.

### 4. Delete Notes

Click the **Delete** button to remove a note.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed.

### Clone the repository

```bash
git clone https://github.com/poorvik12/Notes.git
```

### Navigate into the project

```bash
cd Notes
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
